FOOTBALL ZONE — PREVIEW BUILD

Open index.html in a browser to preview the mobile-friendly app.
The app is a Progressive Web App starter: when hosted on an HTTPS website,
Android users can usually use their browser menu to choose "Install app"
or "Add to Home screen".

IMPORTANT:
- Match scores and stories are demo placeholders, not live information.
- Before public launch, connect a licensed football-data API and a trusted
  news source, add privacy/terms pages, test on devices, and host the app.
- This folder is a web-app starter, not a signed Android APK or a Play Store
  release. Publishing to Google Play requires a developer account and app
  packaging, testing, store listing and review.
